# Sistema Bancario - Consola Java

Este es uno de mis primeros proyectos en el ecosistema Java. Lo desarrollé con el objetivo de consolidar mis conocimientos en los fundamentos del lenguaje y dar mis primeros pasos en la Programación Orientada a Objetos (POO).

## 🚀 Alcance del Proyecto
El proyecto simula las operaciones básicas de un banco a través de la consola de comandos.
